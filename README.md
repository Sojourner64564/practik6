# Практика 6. Автоматический анализ и семантическая обработка видеоданных

Сервис «для журналистов»: вводите слово (например, «ремонт») — получаете ролики, моменты в речи и кадрах,
где это встречается, интерактивную временную шкалу событий и тематическую группировку роликов.

Пайплайн: сбор видео и метаданных → декомпозиция (кадры, аудио) → детекция объектов (YOLO) →
распознавание речи (Whisper) → извлечение событий → кластеризация по темам → визуализация.

## 2. Установка

### 2.1. ffmpeg (обязателен)
ffmpeg и ffprobe нужны для аудио, метаданных, конвертации видео, а также Whisper и yt-dlp.

- **Linux:** `sudo apt update && sudo apt install ffmpeg`
- **Windows:** скачайте `ffmpeg-release-essentials.zip` с https://www.gyan.dev/ffmpeg/builds/,
  распакуйте (например, в `C:\ffmpeg`) и добавьте `C:\ffmpeg\bin` в переменную среды `PATH`
  (`winget` может отсутствовать). **После этого полностью перезапустите терминал и IDE (PyCharm)** —
  иначе они продолжат работать со старым `PATH`.
  Альтернатива без PATH: в начало `config.py` добавить
  ```python
  import os
  os.environ["PATH"] += os.pathsep + r"C:\ffmpeg\bin"
  ```

Проверка: `ffmpeg -version` и `ffprobe -version` должны работать **в том же окне**, из которого запускается проект.

### 2.2. Python-окружение
```bash
python3 -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu   # только CPU
pip install -r requirements.txt
```
При первом запуске скачиваются веса YOLO (`yolov8n.pt`) и Whisper — нужен интернет.
Если GitHub недоступен, скачайте `yolov8n.pt` вручную и положите в папку проекта.

> **Рекомендация:** размещайте проект в папке с латинским путём (например, `C:\practice6`).
> Код устойчив к кириллице в путях (кадры читаются и пишутся через `imdecode`/`imencode`),
> но латинский путь исключает проблемы с внешними утилитами.

## 3. Запуск
1. Впишите источники в `sources.txt` (Rutube/VK или пути к локальным видео; YouTube из-за блокировок может не скачаться):
   ```
   https://rutube.ru/video/ebc42ced8d6858b2ee7b29f3bde1e53e/
   data/my_local_video.mp4
   ```
   Для осмысленной кластеризации тем нужно хотя бы 3–5 роликов на разные темы (максимум 10).
2. Пайплайн:
   ```bash
   python3 run_pipeline.py --sources sources.txt --whisper tiny
   ```
   Флаги: `--whisper small`, `--conf 0.5`, `--method hdbscan`, `--skip-yolo`, `--skip-asr`, `--force`,
   `--stage collect|analyze|aggregate`.
   - `collect` — скачивание и декомпозиция (кадры, аудио); `analyze` — YOLO, Whisper, события;
     `aggregate` — темы, отчёт, дашборд.
   - Повторный запуск пропускает уже обработанное (кэш). События пересчитываются всегда (быстро),
     поэтому `--conf` можно менять без повторного YOLO.
   - Чтобы пересчитать конкретный шаг, удалите его файл в `data/json/` (`*.scenes.json`, `*.yolo.json`,
     `*.loud.json`, `*.asr.json`) или запустите с `--force`.
3. Дашборд: `python3 view_dashboard.py` (порт 8000 или 9000, иначе любой свободный). Введите слово в строке поиска —
   клик по результату или событию на шкале перематывает видео.
4. Консольный поиск: `python3 search.py "ламинат"`
5. Валидация:
   ```bash
   python3 validate.py --n 5      # выборка по 5 событий каждого типа -> out/validation.csv
   # откройте файл, проверьте кадры/видео, поставьте 1 или 0 в колонку verdict
   python3 validate.py --score    # точность по типам
   ```

## 4. События, особенности, ограничения

**События**
- `loud_peak` — громкий момент: уровень окна (0.5 с) ≥ **медиана + 2·(MAD·1.4826)**, где статистика считается
  только по окнам со звуком (> −45 dB). Медиана и MAD — устойчивая замена среднего и σ: паузы между фразами
  не «раздувают» порог. Интервалы из подряд идущих окон объединяются.
- `scene_change` — корреляция HSV-гистограмм (16×16 бинов) соседних кадров < 0.6; повторные срабатывания
  ближе 2 с друг к другу объединяются.
- `object` — класс YOLO непрерывно ≥ 3 с (conf ≥ 0.4).
- `speech` — сегмент речи Whisper (уверенность = exp(avg_logprob)); сегменты с высокой вероятностью «не речь» отбрасываются.

**Особенности**
- Мультимодальность: аудио и кадры анализируются вместе. Шаг кадров считается по fps ролика
  (≈1 кадр/с, потолок 900 кадров на ролик); кадры пишутся на диск по одному, память не растёт.
- Обоснование порогов: YOLO сохраняет все детекции от conf 0.25, для анализа применяется 0.4.
  График `out/conf_sweep.png` и таблица в `out/report.md` показывают число детекций и событий при разных conf:
  ниже 0.4 события почти не прибавляются, выше 0.5 их число падает заметно быстрее.
- Устойчивость к ошибкам:
  - недоступный ролик пропускается, причина пишется в `data/errors.csv`;
  - отсутствие звука фиксируется в `errors.csv`, пайплайн не падает;
  - сбой одного шага (YOLO, Whisper) не останавливает остальные;
  - локальные файлы копируются под ASCII-именем (`local_<hash>.mp4`), чтобы избежать проблем с кириллицей.
- Веб-совместимость: видео с Rutube может иметь кодек MPEG-TS, который не играет в браузере.
  Пайплайн конвертирует такие файлы в H.264/AAC (ffmpeg); дашборд использует конвертированную копию.
- Этика: эмоции и «внимание» по лицам не оцениваются (152-ФЗ).

**Типичные проблемы**
| Симптом | Причина и решение |
|---|---|
| `[WinError 2]` в `decompose` | ffmpeg/ffprobe не найден в PATH → п. 2.1, перезапустить терминал/IDE |
| `object`/`scene_change` = 0, `FileNotFoundError` в `visual` | кадры не записаны на диск → удалить `data/frames`, `data/json/*.frames.json`, `*.scenes.json`, `*.yolo.json` и перезапустить |
| `loud_peak` = 0 | ровная речь без выбросов громкости → уменьшить `LOUD_SIGMA` в `config.py` (например, до 1.5) |
| слишком много `scene_change` | поднять `min_gap` или опустить `SCENE_CORR_THRESHOLD` (например, до 0.5) |
| одна тема в отчёте | кластеризация осмысленна от 3–5 роликов на разные темы |

**Ограничения**
- Поиск в панели — по префиксу (5 букв), в консоли — по лемме (pymorphy3); для идеального поиска нужна
  полноценная семантическая индексация (эмбеддинги).
- Whisper `tiny` ошибается в терминах и именах; для качества используйте `--whisper small`.
- Соблюдайте условия использования платформ: берите небольшое число роликов (до 10) для учебных целей.
